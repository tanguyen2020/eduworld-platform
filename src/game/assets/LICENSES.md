# Asset licenses — EduWorld game client

> Owner: Game Director · Rule: [ADR-0102](../../../docs/adr/ADR-0102-nguon-asset-do-hoa-theo-license-mit-hoac-de-dai-hon.md) · Pipeline: [WORLD_RENDERING §8](../../../docs/08-game-client/WORLD_RENDERING.md#8-asset-pipeline) · Checked by `tools/lint_art.gd` (F067)

Every graphic asset file of the game project (`res://assets/**`, shaders, and any `.glb/.gltf/.png/.jpg/.webp/.svg/.ogg/.wav/.ttf/.otf` outside `tests/` and `addons/`) must match exactly one row below by path (glob, relative to `src/game/`).

- **Allowed licenses** for graphics: `MIT`, `CC0-1.0`, `Public-Domain` (ADR-0102). Project-made assets are released under `MIT`.
- **Fonts** keep `OFL-1.1` (separate decision, [DESIGN_SYSTEM §5.5](../../../docs/05-ux/DESIGN_SYSTEM.md#55-font)); the lint accepts `OFL-1.1` only for font files.
- **Forbidden**: share-alike (`*-SA`), non-commercial (`*-NC`), no-derivatives (`*-ND`), `GPL`/`LGPL`/`AGPL`, paid store packs and any proprietary licence.
- An external asset row needs its exact source URL, author, licence and download date; keep the original licence text next to the files when the licence asks for it (MIT).
