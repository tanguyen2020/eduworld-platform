# design/ — Design tokens EduWorld (F005, ADR-0047)

Nguồn token duy nhất cho **hai design system** (DESIGN_SYSTEM §1–§3): game Godot (`game-tokens/`) và Admin/Ops web (`admin-tokens/`), cùng **mã màu nghiệp vụ** dùng chung (`shared-tokens/`). Định dạng W3C Design Tokens (`$value`, `$type`, `$description`); tầng semantic/component/mode/density/art chỉ dùng alias `{path.to.token}` tới primitive.

| Thư mục / file | Nội dung | Owner |
|---|---|---|
| `shared-tokens/brand.json`, `domain.json` | Brand, môn học/khu vực, độ hiếm, trạng thái nội dung — mỗi màu có `$extensions.eduworld.variants` `light`, `dark`, `game` | Game Director + UX Lead |
| `game-tokens/` | `primitive`, `semantic`, `component`, `art3d`, `density/{g1_3,g4_5,g6_7,g8_9}`, `high-contrast` | Game Director |
| `admin-tokens/` | `seed` (Ant Design), `semantic` (status, chart, banner, `math.font-scale`), `modes/{light,dark,compact}` | UX Lead |
| `fonts/` | Be Vietnam Pro, Baloo 2 + `LICENSE` (SIL OFL 1.1) | — |
| `icons/{game,admin,shared}/` | SVG gốc (chỉ logo + icon nghiệp vụ ở `shared/`) | — |
| `style-dictionary.config.mjs` | Bộ file theo context, file primitive, đầu ra | — |

## Lệnh

```bash
cd design && pnpm install --frozen-lockfile
make design-tokens         # = cd design && pnpm build: kiểm nguồn rồi ghi file sinh
make design-tokens-check   # = cd design && pnpm test && pnpm check: kiểm nguồn + so file sinh + semver với origin/main
cd design && pnpm test       # node --test (transform, format, mọi bộ kiểm)
```

Đầu ra (dòng đầu có `GENERATED by design/ — DO NOT EDIT`, **không sửa tay**):

- Web: `src/cms/frontend/packages/ops-ui/src/theme/antd-theme.ts` (`lightTheme`, `darkTheme`, `compactTheme`, `compactOverrides`, `domainColors`), `tokens.css` (`--ew-*`, `[data-theme="dark"]`, `[data-density="compact"]`).
- Godot: `src/game/resources/ui/theme/eduworld_theme.tres` (density `g6_7`), `eduworld_theme_<band>.tres`, `eduworld_theme_high_contrast.tres`, `fonts/` (bản sao font + OFL); `src/game/scripts/core/ui_tokens.gd` (`class_name UiTokens`); `src/game/resources/art/generated/` (`env_<zone>.tres`, `vfx_<kind>_gradient.tres`, `art3d_tokens.gd`).
- Trung gian (gitignore): `design/build/godot/tokens.json`, báo cáo `design/build/reports/contrast.json`.

## Quy trình đổi token (DESIGN_SYSTEM §8)

1. Sửa JSON trong `design/` (không sửa file sinh). Màu nghiệp vụ chỉ khai báo trong `shared-tokens/` và phải đủ 3 biến thể.
2. Token chữ (màu có đoạn `text` trong `semantic.json`/`component.json`) phải khai báo `$extensions.eduworld.contrastWith: [{ "token": "<nền>", "level": "normal|large|graphic" }]`.
3. Tăng `version` trong `package.json` (đổi tên/xóa token → MAJOR; token bị xóa phải mang `$deprecated` ở phiên bản trước) và thêm mục `## tokens@x.y.z` vào `CHANGELOG.md`.
4. `make design-tokens`, commit nguồn + file sinh trong cùng MR, kèm ảnh trước/sau (Storybook/UI Gallery) và báo cáo tương phản.

Ngưỡng kích thước tối thiểu được đọc trực tiếp từ DESIGN_SYSTEM §5.2 (bảng density) và §4.5 (compact 13 px).
